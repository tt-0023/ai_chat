#多轮AI智能客服会话管理系统（AI Chat Server）
这是一个基于java+Spring Boot开发的多轮AI智能客服后端服务。旨在解决传统AI对话无记忆、接口易被滥用的问题，提供持久化、限流保护以及上下文管理的完整对话解决方案。
##项目背景
普通的AI对话接口往往是无状态的，无法记住用户的历史对话，导致体验割裂；同时，直接暴漏大模型API容易遭受恶意高频调用，导致接口超额扣费。本项目通过工程化手段，实现了多轮对话记忆、频控保护以及会话数据的持久化审计。
## 技术栈
**核心框架**：Java17 Spring Boot 
**数据存储**：mysql(持久化存储），Redis(上下文缓存&分布式限流）
**ORM框架**：mybatis
**大模型接入**：deepseek
**工具类**：Lombok,OkHttp
